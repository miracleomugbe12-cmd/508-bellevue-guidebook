Arrival

Check-In Process

We're excited to host you! Here's everything to make your arrival seamless.

1

Parking

Driveway is recommended. The garage is smaller than a traditional size (1 small car max) — the clicker is inside the home. Street parking is first come, first served.

2

Front door code

Your unique code is sent via "Booking Details" in the Airbnb app — not by the host directly. When unlocking, wait for the lock to whirr twice and come to a complete stop before turning it. Turning too early can cause a failed unlock and lock you out after repeated attempts.

3

Shoes off, please

Use the shoe rack at the front entrance and remove your shoes to help keep the home clean for everyone.

4

Manual keys (optional)

Cowboys key opens the bottom doorknob lock; the gold Minute key opens the Schlage smart lock. We recommend sticking with the electronic lock and leaving the bottom knob unlocked, so you can come and go easily with the door code.

5

WiFi

Connect using either network listed in the WiFi section below.

Before you leave

Check-Out Process

Follow these steps for a smooth, efficient checkout.

  • If applicable, properly dispose of any pet waste — failure to do so results in an additional fee.
  • If applicable, clean the grill if it was used — failure to do so results in an additional fee.
  • Load and run the dishwasher with any used dishes (do not use the heat function).
  • Place all towels in the washer, add 1 Tide pod, and run a cold wash. Drying them too, if you're able, is a big help.
  • Throw away all trash, including refrigerated items. If more than 2 bags, place them in the outdoor trash can on the side of the house.
  • Gather all belongings — any leftover items will be discarded and not shipped after checkout.
  • Set the thermostat to 72–74°F.
  • Return any moved furniture or items to their original positions.
  • Secure the property — make sure all windows are closed and locked.
  • Turn off all lights and appliances.
  • Return the garage clicker and house keys to the black key holder near the front door.
  • Lock the front door using the electronic lock.

City of Arlington

Trash Pickup

Pickup is every Wednesday morning.

Take any trash to the outdoor bin, or add to the bin if one was already left from a previous stay. Place the bin in the middle of the curb between the two homes — the trash service will not collect anything left next to the mailbox. Keep it clear of the driveway and out of the neighbor's way. Once collected, please return the bin to its original spot at the side of the house.
